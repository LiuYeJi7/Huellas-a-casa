Descripción del Negocio
Este proyecto web es una solución de comercio electrónico adaptada a la temática de un refugio de adopción de perritos. La plataforma permite a los usuarios visualizar una sección de productos destacados, navegar por un catálogo generado dinámicamente y manejar aportes económicos a través de "cuotas de adopción" o "kits de apadrinamiento".

Instrucciones de Uso
1.	Ejecución Local: Descomprime el archivo ZIP del proyecto, el cual está organizado bajo la estructura requerida de carpetas (/css, /js, /img, /pages). Abre el archivo principal index.html en tu navegador web. 
2.	Versión en Línea: Puedes visualizar el sitio web desplegado en vivo ingresando a nuestra URL alojada en [GitHub Pages / Netlify]. 
3.	Catálogo y Detalles: Navega por el catálogo de perritos, utiliza los botones para filtrar por categoría y haz clic en "Ver detalles" para abrir el modal con la imagen ampliada y la descripción completa.
4.	Carrito de Compras: Al presionar "Apadrinar", verifica cómo el contador en el ícono de la barra de navegación se actualiza dinámicamente. Puedes recargar la página para comprobar que los datos no se pierden gracias al uso de localStorage.
5.	Checkout: Abre el modal de la lista de apadrinamiento y procesa el formulario; el sistema incluye una validación en tiempo real programada en JavaScript que mostrará mensajes de error si los campos están incompletos o son incorrectos.
Stack Tecnológico
•	HTML5: Uso estricto de etiquetas semánticas (<header>, <nav>, <main>, <article>) para cumplir con los estándares de accesibilidad WCAG. 
•	CSS3: Implementación de propiedades personalizadas (variables en :root) y animaciones (@keyframes).
•	JavaScript (Vanilla JS): Creación del motor lógico del sitio sin el uso de librerías externas no permitidas como React o jQuery.
•	Bootstrap 5: Uso de la grilla y componentes bajo el enfoque Mobile First para garantizar la responsividad en celulares, tablets y computadoras de escritorio
